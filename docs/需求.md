## 交付内容

项目在 `wechat-lowlevelcv/`，四个产出点对应你的四项要求：

**1. 系统架构** — FastAPI + APScheduler + SQLite + OpenAI 兼容客户端（DeepSeek/通义/智谱都能换），单机 `uvicorn app.api:app` 即起，带运营控制台。选型理由写在 README 第 1 节，核心思路是「运营改配置不改代码」：题词表、阈值、数据源、排期、主题色全在 `config/topics.yaml`。

**2. 爬虫层** — `app/sources/` 每源一个模块：
- `lowlevelcv.py`：实测过页面结构（`h3` 标题 + `sumBox` 摘要 + `imgBox` 图 + `m1/m2` 链接），`?current=N` 翻页，测试用真实页面夹具
- `arxiv.py`：官方 API + 架构图提取（HTML 按 caption 关键词挑图 → PDF 首页渲染兜底）
- `industry.py`：RSS/Atom 通用；`github_trending.py`：GitHub 开源源
- `competitions.py`：Kaggle API / 天池 / 搜索 / NTIRE·MIPI 策展页

**3. Prompt 模板** — `app/llm/prompts.py`：一个共享 System（人设+文风+事实纪律）+ 三张模块任务卡，输出约束成 `ArticleSpec` JSON。**模型只写内容，排版交给模板**，这样每期版式不会飘。强 JSON mode + 括号配平修复 + 失败回传自修。

**4. 微信排版转换器** — `app/render/wechat.py`：全内联样式（公众号会剥离 `<style>` 和 class），主色随模块切换，论文信息卡/赛事卡/高亮块/深色总结卡，`table-layout:fixed` 表格。预览页有「复制富文本」按钮；推草稿时本地图自动走 `media/uploadimg` 换 CDN。

## 三个必须知道的坑（已修）

1. **筛选全空的根因**：`seen` 快照原先在写库之后取，等于把刚抓到的条目当成「已用过」。顺序调换才通。
2. **RSS 静默失败**：`feedparser` 遇到反爬返回的 HTML 不抛异常，只给 0 条。现在逐路记录 `count / error / 返回内容前 120 字`，通过 `/api/sources → rss_health` 和控制台「源告警」暴露。
3. **arXiv 配图拖死流程**：PDF 首页渲染在慢网络下能把一次出稿拖到 23 分钟。已改默认关闭 + 只给前 3 篇补图 + 每源硬超时。

另外，本机网络实测发现 `jiqizhixin`、`huggingface`、`research.google` 和 RSSHub 公共实例都被代理挡了（502），所以业界模块补了 GitHub 开源源兜底 —— 顺带解决「开源项目没有配图」的问题，用仓库官方 OpenGraph 图（1200×630）。换网络环境后先跑 `python -m scripts.check_sources` 确认哪路能通，别靠猜。
